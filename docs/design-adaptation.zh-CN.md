# 把设计参考适配为项目准则

[English](design-adaptation.md) · [首页](../README.zh-CN.md)

设计适配能力及场景参考库随 [1.7.0 网关](https://github.com/arctan303/creator.skill/releases/tag/v1.7.0)提供。下载网关不会自动安装工作流，也不会自动修改项目文档。

## 通过网关发起适配任务

让代理读取解压后的 1.7.0 [creator 网关](../gateway/SKILL.md)，说明目标项目、相关页面和允许修改的文档。设计适配是自然语言任务，不是安装器参数；即使目标项目尚未安装工作流，也可以独立进行已授权的文档适配。

新项目可以这样说：

> 使用 creator 网关，为这个小型待办网页建立设计准则。沿用现有 tokens，只采用相关场景。创建一份项目设计文档，并从现有 README 链接它。本次只改文档。

已有项目可以这样说：

> 完善现有表单和列表规范，补充保存失败反馈和次要元数据层级。保留英文文件、直角、整体 Save，以及已经确认的复杂编辑器弹窗例外。只修改设计入口和它的两个主题文件。

以后比较资料更新时可以这样说：

> 对比参考库的相关更新和项目已采用的规则。保留本地修订，说明值得采纳的变化，再完成已授权的文档更新。已有规则充分时保持原样。

代理先读取项目现状、设计入口及适用的条件引用、有效决定、组件和 tokens，再按[共享适配程序](../.creator/references/design-adaptation.md)从[参考库索引](../design-library/README.md)选择相关资料。

## 按场景选择，再形成项目决定

参考库包含九个可组合模块。一个产品可以使用多个模块，小任务也可能只需要一个模块及相关基础规则。

| 模块 | 常见适用范围 |
| --- | --- |
| [基础视觉与交互](../design-library/foundations.md) | 字体、间距、色彩、一致性和无障碍 |
| [表单与设置](../design-library/forms-and-settings.md) | 控件、校验、保存语义和草稿 |
| [后台与数据管理](../design-library/admin-and-data.md) | 表格、筛选、批量操作和对象详情 |
| [仪表盘与监控](../design-library/dashboards-and-monitoring.md) | 指标、图表、时间范围和数据可信度 |
| [内容阅读与文档](../design-library/reading-and-documentation.md) | 长内容、导航、搜索和阅读密度 |
| [媒体与资源浏览](../design-library/media-and-browsing.md) | 网格、预览、选择和队列 |
| [工作台与编辑器](../design-library/workspaces-and-editors.md) | 分栏、工具、快捷键、撤销和恢复 |
| [登录、初始化与引导](../design-library/onboarding-and-access.md) | 进入产品、必要输入、权限和首次使用 |
| [品牌、营销与作品展示](../design-library/brand-and-marketing.md) | 视觉叙事、表达性内容和转化 |

新项目建立最小且够用的本地设计文档；已有项目在原文档中补足已确认的缺口、对账受影响条款。保留路径、语言、品牌选择、保存行为和局部例外。不要把所有模块复制进项目，也不要把整理文档理解为重新设计界面。

简短来源说明记录采用模块、实际读取的资料修订、适用范围和重要本地例外。它是出处，不是运行时依赖：项目文档本身应包含采用后的决定，或指向其本地归属文档。新规则表达预期行为，不代表界面已经实现或通过验收。

## 日常工作继续读取本地规范

日常 UI 开发、修复和审查读取项目已采用的设计入口及其适用引用，无须读取网关或上游参考库。资料升级只为下一次已授权适配提供候选建议，不会静默采纳新规则或覆盖本地修订。

安装和适配是两项独立操作。归属感知安装器管理工作流文件并保留项目文档；确定性脚本不会进行设计语义合并。仅请求设计适配，不代表授权安装、发布或修改文档范围之外的内容。

## 使用发布版网关

从 [1.7.0 Release](https://github.com/arctan303/creator.skill/releases/tag/v1.7.0) 下载 `creator-gateway.zip`，解压到临时目录，让代理读取其中的 `SKILL.md`。网关包含作者参考库；用于项目安装的 `creator-workflow.zip` 包含简短日常流程。如需同时安装或升级工作流，见[快速开始](quickstart.zh-CN.md)。

明确使用选定的已解压网关；若要主动更新可选个人技能，先阅读[网关加载说明](../gateway/references/cli-adapters.md)。

交付应说明修改的文档、采用来源、保留决定、未解决冲突和实际检查。文档检查、应用实现、视觉验证与发布证据分别报告。
