# 1.6 bounded agent behavior evidence

Observed 2026-10-14 in the local Codex session. This is a synthetic task smoke test, not a production migration, statistical benchmark, old/new comparison or live Claude Code test.

## Method

Prepared three workspaces with `prepare_behavior_run.py prepare --output .creator/evaluations/1.6-smoke`. Each received a copy of the canonical policy/skills/references, its small project documents and TASK.md. Expected fields, cases.json, scenarios.json and the private baseline were absent from each workspace.

A fresh subagent with no parent conversation history executed all three scenarios, instructed to read only those workspaces. The scenarios shared that subagent session; they were not three independent model samples. The boundary was instruction-scoped, not an OS sandbox. No cross-model or historical baseline run was performed.

The main session inspected actual output files and compared file hashes with the private pre-run baseline. All three scope checks passed: only the five allowed output/document files changed; original read-only evidence remained unchanged. File-scope checks do not grade semantics; the observations below are from reading the actual output.

## Limits and reproduction

Reproduce with a new output directory, pass only generated TASK.md workspaces to a fresh agent, then use `inspect` and independently review actual files. A failed attempt must remain evidence; do not repeat unchanged input until a preferred answer appears.

The raw local run remains under ignored `.creator/evaluations/1.6-smoke/`; its private baseline stores per-file SHA256. This checked-in report preserves the method and observed results. These three scenarios do not establish universal model adherence, real application correctness, actual subagent efficiency, or host discovery. The 46 structured policy cases are separately validated for structure and are not reported as 46 executed model tasks.
