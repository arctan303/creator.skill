# 仪表盘与监控：从数字走向判断

> 参考材料，未采纳不生效。本文供设计适配阶段选择和解释仪表盘规则；日常开发使用项目已采纳准则，不直接继承本库。

适用：运营概览、运行状态、业务分析、容量观察和告警分诊，尤其是需要从概览进入具体对象的页面。
不适用：为后台首页填空白而添加指标卡，或用图表替代用户真正需要的查找、编辑和核验任务。
“数据感”不决定深色主题、荧光色、大量环形图或实时动效；主题与密度应由设备、时长、品牌与任务决定。
本文不定义业务阈值、统计口径或告警权限，也不将展示阈值视为自动处置授权。

## 先选仪表盘服务的判断

适配时把页面目的写成可以回答的问题，例如“现在有无故障”“变化发生在哪”“需要先处理哪一项”。
不同目的可以共享数据，但不必共享同一布局；管理者月度复盘与值班人员实时排障的优先级往往不同。

| 使用场景 | 默认候选 | 理由与代价 |
| --- | --- | --- |
| 日常运营概览 | 少量关键指标、趋势和异常入口 | 形成行动线索；不能只剩漂亮数字 |
| 值班监控 | 当前异常、影响范围、新鲜度、分诊列表 | 优先发现与定位；次要长期趋势可后置 |
| 周期复盘 | 明确时间段、可比口径、变化解释 | 支持理解；不必每秒刷新 |
| 探索分析 | 可理解筛选、钻取、明细与口径 | 允许回答新问题；复杂度与查询成本更高 |
| 展示大屏 | 远距可读、固定范围、清楚更新时间 | 便于观察；复杂编辑与密集 tooltip 不合适 |

没有可以据此判断或行动的指标，先作为候选而非默认首屏；“数据已经存在”不足以证明值得展示。
概览不是所有数据的缩略图集合；用户要看原始记录时，应有清楚的明细入口与上下文。
主要任务本来是管理资源时，可直接落到[后台与数据管理](admin-and-data.md)的列表，而不是必经仪表盘。

## 指标口径与比较关系

每个关键指标说明对象、单位、时间范围和必要分母；“成功率 98%”不足以判断统计了什么。
显示比较值时明确是环比、同比、前一等长周期还是目标；增长并非总是好消息，错误率上涨更不能配“庆祝”语义。
缺失、不适用、尚未聚合和真实零分别表达；不要用“0”填补请求失败或延迟数据。
口径说明可以紧凑展开，但关键的周期、单位与范围应在判断位置可见；不让读者逐个打开帮助才知道在比什么。
跨图共享筛选时清楚表达作用范围；某张图使用不同口径时就近标出，不让统一页头造成错误比较。
四舍五入、币种、时区和数量级由项目定义；必要时可查看精确值，不让缩写掩盖重要差异。

| 对比问题 | 可选表达 | 适用边界 |
| --- | --- | --- |
| 一段时间如何变化 | 折线或适合的时间序列图 | 连续与缺口有实际含义，不能把无数据连成确定趋势 |
| 不同类别谁多谁少 | 条形图或对齐数值列表 | 类别多时关注排序、长标签与可读性 |
| 一个数字是否达标 | 数值、目标与差值 | 不必为了一个百分比默认增加仪表盘或环图 |
| 组成占比 | 堆叠条、简单组成图或表格 | 类别过多、近似值比较时图形可能更难读 |
| 精确查值和审计核对 | 表格或可访问明细 | 图表可以补充趋势，不替代精确核验 |

以上是场景候选，不是图形种类禁令；选择应通过真实数据验证比较是否准确。
图表标题说清它回答的问题，必要注释交代异常和口径变更；不在标题、图例和描述重复同一句话。
不采用会制造不存在差异的比例或装饰透视；坐标范围、截断与聚合需要支持正确解读。

## 布局、层级与交互

优先安排用户最先需要判断的区域，再按解释路径展开：异常或结果 → 变化 → 分解 → 对象明细。
指标不必等宽等高；若重要性与内容不同，机械网格会掩盖层级，空白也会被无关图表填满。
卡片适合独立模块，但边框、阴影、渐变和图标不应同时成为每个指标的默认装饰。
图例靠近图表并说明系列，长名称允许换行；依赖颜色识别时补足线型、标签或其他可区分信号。
交互 tooltip 能提供局部值，但不是唯一信息入口；键盘、触控与辅助技术用户也要取得关键结论与数据。
钻取保留可理解的时间、对象与筛选上下文；返回时是否恢复状态沿用项目契约。
下载与分享属于独立产品能力，不能仅因图表库有按钮便启用；范围、权限和敏感口径需要项目决定。
图表组件与数据加载优先使用项目现有工具；本参考不要求某个框架、可视化库或第三方服务。

## 实时性、新鲜度与告警

“实时”需要可解释的采集与刷新契约；显示最后数据时间，必要时区分采集时间、聚合完成与页面刷新时间。
刷新周期由任务与成本决定，页面轮询频率不能自动证明数据源同样新鲜。
刷新已有内容时保留仍有价值的数据，并可见标出过期或正在更新；不反复清空图表造成跳动。
连续数据缺口应作为缺口或未知表达；不得用前值平滑伪装正常，也不把延迟当作归零。
新增异常可以更新计数与列表；不要在用户操作筛选或读明细时频繁抢焦点、自动滚回顶端。
告警等级用项目业务定义表达影响与紧迫性，颜色仅辅助；不同品牌或领域的颜色约定不能冒充普遍标准。
已确认、静默、已恢复与已解决可能是不同业务状态，需要定义；“静默”通常不等于故障消失。
如果项目支持暂停刷新，区分仅冻结视图与停止采集；不能让用户误解为后台监控已经停用。
告警动作显示实际影响和权限边界；确认告警、关闭告警和修复根因不能被一个模糊按钮混同。

## 关键状态

| 状态 | 可观察表现 | 避免的误导 |
| --- | --- | --- |
| 初次加载 | 明确正在获取哪些范围，结构保持稳定 | 骨架永久闪动且无失败出口 |
| 数据为空 | 说明尚未采集或范围内无记录 | 把无记录写成“一切正常” |
| 全部为零 | 零有明确统计口径和有效时间 | 失败数据被转成零 |
| 部分数据延迟 | 标明受影响指标与最后有效时间 | 总体仍显示“刚刚更新” |
| 单模块失败 | 保留其他有效区域并就地重试 | 因一张图失败清空整页 |
| 筛选无结果 | 显示当前范围并允许调整 | 暗示数据源本身没有数据 |
| 阈值异常 | 标明影响、时间与分诊入口 | 只有红点，没有事实和下一步 |
| 刷新恢复 | 恢复真实数据并标出当前时间 | 把“连接恢复”直接写成“故障解决” |

必要状态消息可以由辅助技术感知，但不将每秒变化的数字逐个高优先级播报。
图表不能只提供笼统的“图表”替代文字；关键结论、趋势与必要值需要等价的文字或结构化信息。
静态图可用简短识别加长描述；交互图仍需检查操作语义与可达性，不能只补一个 alt 就宣称可访问。
减少动态效果时应保留变化事实；关闭柱形动画不意味着删除异常反馈。

## 反例与有意例外

反例：八个指标都用同样的上涨绿色箭头，其中四个其实是成本和失败数；视觉一致造成业务含义错误。
反例：每张图默认不同时间范围、不同单位，页头仍写“本周”；看似整齐却无法正确比较。
反例：数据请求失败后显示 0 和“系统健康”，把信息缺失包装成成功结论。
有意例外：为定位剧烈波动采用非零起点的折线，需要清晰坐标与范围；不把某种起点规则机械用于全部图表。
有意例外：展示大屏无法承载复杂交互，可以保持少量摘要，但应提供适合近距离排障的其他路径。
有意例外：专业分析者需要密集多图联动，复杂度有任务依据；不为“极简”删除必要维度。

## 项目化例子与可观察验收

例：消息服务的值班首页服务“发现发送失败并定位队列”。项目采纳异常队列优先，其次显示同一小时范围的失败率与待发量。
每张图写明单位、时区和最后有效采集时间；故障队列可钻取，进入明细携带同一时间范围。
一个区域延迟时显示“数据截至 10:42”，其他区域保持可用；重连成功不宣称积压已经清空。

- 用零、缺失、延迟、突增与部分失败样本检查结论，确认页面没有把未知显示为正常。
- 让使用者从异常概览进入受影响对象，能解释范围与口径；仅“看起来数据丰富”不是验收结果。
- 对照原始数据核对单位、聚合与比较周期，检查四舍五入是否改变重要判断。
- 用键盘和触控取得关键值与趋势；关闭颜色或减少动效后仍能识别重要差异。
- 在窄屏、放大和长标签下查看图例、坐标与明细，确认文字可读且交互区域未被覆盖。
- 核对更新时间来自真实数据契约，刷新、失败与恢复的反馈不抢走当前任务焦点。

## 已核实的一手来源

核实日期：2026-11-11。图表候选和监控状态是任务导向综合；来源没有替项目定义指标、阈值和业务动作。

- [USWDS Data visualizations](https://designsystem.digital.gov/components/data-visualizations/)：可视化应提供帮助理解的数据表达与可访问替代，按数据与任务选择表现。
- [Carbon Data visualization overview](https://www.carbondesignsystem.com/building-blocks/data-visualization/overview)：提供多类图形的选择范围，不代表应全部采用或固定技术栈。
- [W3C Complex images](https://www.w3.org/WAI/tutorials/images/complex/)：复杂图表提供简短识别与表达关键信息的长描述，描述可向所有人提供。
- [W3C 状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)：让必要动态结果可被感知，避免无谓打断。
- [WCAG 重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：二维关系的例外有范围，图表周边普通内容仍需可重排。
