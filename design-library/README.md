# 场景设计参考库

资料修订：`2026-11-11.1`。这是设计适配时使用的作者资料，不是项目默认规范，也不表示工作流已发布新版本。**参考未被项目采纳，不对该项目生效。**

本库随 creator gateway 提供；普通 workflow 包不包含本库。日常设计实施、修复和审查读取项目实际采用的规范与本地条件引用，无须访问本库或网关。上游资料更新不会自动改变项目要求。

## 如何选择

1. 网关先读取项目现状、用户任务、已有设计入口和有效例外，按共享 design-adaptation 流程执行；设计决策复用 design-brief-builder，文档归并复用 project-knowledge。
2. 根据页面里的真实任务选择下面的少量模块，同一仓库可以采用不同组合。已有规则充分时可以保持原样，不为展示“做了适配”强行新增条款。
3. 只把合适建议改写成本项目的具体决定。保留已有字体、组件、保存语义与品牌；有真实未决体验取舍才问用户。不能把示例数字、备选风格、引用网页或整章正文自动提升为规则。
4. 在现有设计文档里保留简短来源说明：本库修订、采用模块、范围及重要本地例外。正文要足以指导项目工作；来源链接是出处，不是要求日常开发继续读取上游。
5. 新项目通常一份设计文档就够；已有项目原位补充相关主题和导航。用户自有文档不成为安装器受管文件，不因资料更新被覆盖。

## 参考如何变成项目决定

参考中的“简单设置考虑原位操作”，需要结合本项目任务、频率和保存契约来选。若用户已决定把账号的五项配置放在页面中，而项目仅有整体保存接口，可采纳为：

> 账号设置页直接展示五项既有控件，共用一份草稿和页面末尾的保存区；保存成功后更新已保存值，失败保留输入并在保存区提示。复杂密钥连接编辑器仍使用已确认的独立弹窗。

这条本地规则说明适用页面、状态和例外。不能仅写“遵循表单模块”，也不能据此把所有设置页改成自动保存或撤销其他弹窗。

已有直角、紧凑字号、特殊阅读布局或明确品牌动效时，参考库用于发现相关空白和解释取舍；这些本地决定不因某示例采用圆角或另一字号而失效。冲突不能靠“较新的文件”或“更多项目这样做”决定。

## 内容与证据约定

- 模块中的默认做法是候选建议，例外也需要符合具体任务；必要可用性和平台要求仍按项目实际目标核对。
- 每个模块提供适用边界、场景决策、关键状态、反例、项目化例子、可观察验收和来源；引用支持设计判断，不等于所有结论都出自同一标准。
- 数值如作为起点，会明确其适用条件；不把行业、地域或模型偏好写成通用品牌要求。
- 项目已有设计系统或原生平台控件优先作为实现依据；本库没有提供一套可直接安装的组件库。
- 未核验的推断保留为候选；新采用规则是目标，不代表当前界面已实现或通过验收。
- 后续资料修订按模块维护来源及差异。再次适配时比较当前本地规则和有用变化；不自动整份再生成，不反复复制同义内容。

## 研究来源与采用方式

规则基于模块内列出的一手设计系统、可访问性资料及独立综合。还参考了以下技能的组织方法，未复制其整套规则或执行其工具：

- [Impeccable](https://github.com/pbakaus/impeccable/tree/c1e0e5492fbb524f5df84d635ecfae7dc438ec45/skill/reference)：按任务区分操作、阅读、表达等页面，聚焦具体设计问题，维护既有设计上下文。
- [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)：从产品内容产生视觉方向，关注文案和有意的表达；不将表达性建议强套到操作界面。
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/blob/6ae86f61f520d6ca229d2f40e070410638c908c5/src/ui-ux-pro-max/templates/base/skill-content.md)：按场景检索并检查匹配后持久化；不继承未经项目验证的行业与风格绑定。
- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/434b7f91364665f2f733b310ec54809bf8f37937/command.md)：将实现质量转为可检查项；不把跨语言文案偏好或网页实现细节用于所有平台。

详细来源随相关模块维护。链接会更新；具体平台行为或标准版本有变化时在适配任务里核实，不在每次普通开发中自动下载新规则。
