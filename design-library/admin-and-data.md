# 后台与数据管理：查找、比较和批量操作

> 参考材料，未采纳不生效。本文只供设计适配阶段裁剪为项目规则；日常开发读取项目已采纳准则，不直接继承本库。

适用：资源管理、成员或插件列表、审批队列、记录查询，以及需要扫描、筛选和比较的业务后台。
不适用：把所有对象都做成表格、替代完整电子表格产品，或为展示技术能力而附加没有任务用途的筛选与图表。
后台不等于某种颜色或高密度；频率、比较需求、权限与数据风险比“专业风”标签更能决定结构。
以下建议不授权删除、批量修改或外传数据；界面上存在按钮也不代表用户或代理已获执行权限。

## 从管理对象与工作流出发

适配时选一个高频任务，例如“找出连接失败的插件并重试”，明确对象、状态、范围与结束条件。
列表首先支持该任务；内部 ID、协议版本或 API URL 是否首屏可见，取决于是否参与识别和决策。
不能因“去技术化”隐藏核验来源、兼容性、权限和数据去向需要的信息。

| 任务事实 | 默认候选 | 理由与代价 |
| --- | --- | --- |
| 同类对象按多个属性比较 | 表格或对齐行列表 | 同列便于比较；窄屏需要处理二维关系 |
| 一个对象的若干事实 | 键值摘要 / 描述列表 | 清楚表达属性关系；不冒充多对象比较 |
| 图片或异质内容为主要识别依据 | 卡片或混合列表 | 视觉浏览有价值；注意扫描与操作成本 |
| 少量简单对象，只有一个动作 | 简单列表 | 降低结构负担；无需自动增加工具栏 |
| 大量单元格编辑与公式计算 | 专用数据编辑体验 | 普通管理表格可能不足；不能假装等同电子表格 |

页头说明管理对象与主要范围；已有导航和表名足以定位时，不再增加一套口号、欢迎区和重复说明。
有创建任务才展示明确创建入口；只读审计页不需要为了布局平衡硬造主操作。
列表、详情和编辑保持相同对象名称与状态词汇，避免“已断开”“未连接”“离线”无定义地混用。

## 列、行与信息密度

选择列时优先考虑识别对象、做决定和执行动作所需的信息；不按数据库字段顺序全部平铺。
列标题说明含义与必要单位；数字依据比较需求对齐，日期格式与时区沿用项目约定。
缺失、不适用、零与未知需要区分，避免统一用“—”让用户猜；可用简短文字或有解释的表示方式。
长名称可换行或按需展开；截断时保留可获得完整值的路径，不能仅靠鼠标悬停。
技术详情可以进展开行或详情页；如果用户必须横向比较该字段，则不宜藏到每行展开区。
行高、文字角色与动作目标使用项目密度尺度，别以填满宽屏为目的拉大短值和控件间距。
行点击导航与行内按钮需要清楚区分；不要让勾选 checkbox 同时打开详情。
固定表头或关键列可帮助大表比较，但会占用空间；需检查放大、窄屏与键盘焦点未被遮挡。

## 搜索、筛选、排序与分页

先确定用户如何描述目标，再选择文本搜索、枚举筛选或组合条件；不默认把每一列都变成筛选器。
搜索范围需要可理解：名称、当前页、全部对象还是当前工作区；搜索框占位不能替代可访问名称。
筛选显示当前条件及清除入口；“没有对象”与“当前条件无结果”提供不同下一步。
排序只在有真实比较需求的列提供，清楚表达当前列和方向；不要让点击状态图标偶然排序。
稳定排序需要可预期的同值处理，避免刷新后相同行无规律跳动；具体算法是实现选择。
分页、加载更多或滚动加载按定位与规模选择；审计回看可能比连续浏览更需要稳定页位置。
改变搜索或筛选时，页码、滚动与选择如何变化需要项目规则；不要让旧选择悄悄应用到另一组对象。
返回列表时可按既有契约保留查询上下文；本参考不自动要求跨设备、跨会话持久保存。

| 场景决策 | 可选默认 | 有意例外 |
| --- | --- | --- |
| 短条件是否即时筛选 | 成本低、无提交副作用时可即时 | 高成本查询可用明确“应用筛选” |
| 筛选是否影响导出 | 就近说明“当前结果”或“全部” | 后台生成全部导出可独立配置范围 |
| 分页后选择是否保留 | 保留时持续显示总数与范围 | 仅当前页选择也可行，但需清楚标识 |
| URL 是否编码查询 | 分享或恢复任务需要时采用 | 敏感条件不能随意暴露到地址与历史 |

## 单项、批量与危险操作

动作名称说明真实结果，例如“重试连接”“移除成员”；不把不同后果都叫“处理”。
批量操作先解决范围认知：选了几项、是否跨页、是否包含过滤不可见项、有哪些不适用项。
“选择当前页”与“选择全部结果”需要明确区别；后者不应通过含糊的全选框默默扩大。
批量动作可以在选中后出现，让默认工具栏保持清楚；仍要有取消选择和当前范围。
提交前已知的权限或状态限制应表达，执行时仍由服务端验证；灰色按钮不能代替真实授权控制。
有部分成功的操作，分别报告已完成、失败与未执行范围，保留可行动的失败对象。
重试避免无意重复已经完成的不可重复动作；实际幂等、事务和重试能力以产品契约为准。
危险动作在决策位置说明对象、后果和真实恢复条件；不对每次低风险操作堆叠同一长警告。
可撤销方案只有后端确实支持时才展示“撤销”；界面不能用一条 toast 虚构数据恢复能力。
表内编辑保留字段类型及整体 Save 契约；不要为了减少弹窗改成无条件单元格自动保存。

## 关键状态与反馈位置

| 状态 | 可观察表现 | 反例 |
| --- | --- | --- |
| 初次加载 | 说明正在获取对象，结构保持稳定 | 空白几秒后突然跳出表格 |
| 刷新中 | 保留仍有用的旧内容并交代刷新 | 每次轮询清空列表、丢失操作焦点 |
| 从未创建 | 解释当前范围，存在权限时提供创建路径 | 对只读角色显示不可用“立即创建” |
| 筛选无结果 | 展示条件、清除或调整入口 | 当成系统没有任何数据 |
| 无权限 | 说明可见范围与适用下一步 | 伪装成空表或输入格式错误 |
| 请求失败 | 保留查询条件与可恢复内容，给真实重试 | 只显示“发生错误”然后全部清空 |
| 批量部分失败 | 成功和失败数、失败对象与后续选择 | 只给“操作成功”并隐藏失败项 |
| 对象已被别人修改 | 按真实并发契约解释变化与恢复 | 静默覆盖或丢弃本地草稿 |

必要操作反馈靠近受影响区域；短暂通知可补充结果，但不承担需要处理的失败清单。
状态变化的辅助技术提示控制粒度，播报结果摘要，而不是每次筛选重读所有单元格。
表格结构与键盘路径需与组件能力匹配；不要随意添加 grid 角色却缺少对应键盘模型。
窄屏可以区域滚动、减少非必要列或提供等价详情；不把数据表的二维例外推广到整页横向滚动。

## 反例与项目化例子

反例：插件列表每行变成五张卡片，版本、ID 和来源占据大面积，重试却藏在不明图标中。
候选改进：按名称、连接状态、必要兼容信息和动作组成行列表，技术详情集中，来源仍可核验与复制。
有意例外：用户通过封面识别素材库对象，卡片保留图片与少量元数据，列表视图可按真实比较需求补充。
有意例外：安全审计任务必须核对原始 ID 与完整地址，这些字段可以保持可见并提供复制，而非一律降级。

例：设备后台需要筛出“离线超过一天”的设备并派发重连。项目采纳“状态+最后通信时间+设备名”的默认列，筛选显示时区和范围。
选中 12 项后工具栏说明范围；其中 2 项不支持重连，提交结果分别列出 10 项完成与 2 项未执行及原因。
进入一项详情返回时保留有效筛选；是否保留选择由原有契约决定，不从本例推导额外持久化能力。
若操作不可逆或存在真实成本，项目需明确对应确认与授权边界；此例本身不提供执行授权。

## 可观察验收

- 用真实长名称、重复值、缺失值和大量记录完成查找与比较，关键列无需逐项打开详情才能判断。
- 更改筛选、排序、页码后检查当前范围、选择数量与操作目标；不存在静默扩大范围。
- 执行有代表性的单项与批量路径，覆盖部分失败、权限变化和刷新；结果与对象实际状态一致。
- 键盘选择行、操作菜单、进入详情再返回，焦点清楚且未被固定区域遮挡。
- 放大和窄屏下，必要二维滚动局限在表格区域，页头、筛选及主要动作仍可使用。
- 若修改编辑布局，核对字段类型、提交载荷、Save/取消与错误恢复没有被顺带改变。

## 已核实的一手来源

核实日期：2026-11-11。下列资料支持结构与状态原则；范围、并发与批量恢复方式由项目业务契约决定。

- [Carbon Data table](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines)：表格支持比较、工具栏、排序、选择与批量动作，也明确不是电子表格应用的替代。
- [GOV.UK Summary list](https://design-system.service.gov.uk/components/summary-list/)：描述列表适合键值事实，不替代表格或普通列表。
- [Carbon Notification](https://www.carbondesignsystem.com/building-blocks/core/components/notification/guidelines)：按任务与打断程度选择反馈，谨慎使用通知。
- [WCAG 重排](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)：二维数据表有范围明确的例外，普通内容仍需重排。
- [W3C 状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)：异步结果摘要的可感知性，避免不必要打断。
