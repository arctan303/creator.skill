# 媒体、资源浏览与选择

> 参考资料，未被项目明确采纳前不生效。用于编写项目自己的设计准则；本模块不构成日常 UI 任务的直接规则，也不授权新增播放、分享、上传或追踪能力。

## 适用边界

- 适用：图片库、音视频目录、附件选择器、素材浏览和以视觉识别对象的集合。
- 不直接套用：需要逐列比较的业务记录、纯正文阅读、编辑器时间线；内容集合不必都做成媒体墙。
- 先区分“找一项”“连续欣赏”“比较候选”“选中后提交”；一个缩略图不能同时隐含四种动作。
- 图片网格适合视觉差异，行列表适合名称、作者、时长和状态扫描；视图切换需要真实用途。
- 参考库不决定版权、存储、下载权限、推荐算法和外部媒体服务；这些来自项目有效契约。

## 选择布局前需要的事实

1. 用真实资源确认主要识别线索：封面、文件名、时间、类型还是作者。
2. 确认缩略图可否裁切，透明图、竖图、长图和缺封面如何保持可辨认。
3. 确认单选、多选、批量操作与播放是否已存在，选中状态的生命周期是什么。
4. 核对现有播放器、选择控件、焦点行为、排序和分页能力，不因浏览风格新增复杂组件。
5. 确认网络、格式、权限和版权状态会在哪一步阻止实际使用，必要条件进入该决策位置。

## 主要决策与取舍

| 决策 | 适合的起点 | 必须解决的代价 |
| --- | --- | --- |
| 网格或行列表 | 以封面识别用网格，以属性比较用行 | 网格不能只剩图片；行列表也需保留识别线索 |
| 统一比例或保留原比例 | 统一比例便于扫视，原比例保留构图 | 明确裁切与留白策略，不能把裁切预览误当原图 |
| 分页或连续加载 | 找回位置与定位重要时考虑分页；连续浏览可渐进加载 | 两者都要处理返回、键盘到达后续内容与真实加载失败 |
| 点资源的行为 | 明确是查看详情、播放还是选择 | 不能同一点击有时播放有时勾选，靠猜测模式 |
| 放大预览或独立详情 | 临时核对可用轻量预览；丰富元信息适合详情 | 关闭后返回原资源和合理位置，保留既有状态契约 |
| 播放器固定或随内容 | 持续收听时可考虑固定区域 | 不遮住操作和字幕，不默认承诺跨页继续播放 |

以上是任务取舍，不是任意项目都必须提供两种视图、无限滚动或固定播放器的功能清单。

## 网格、元信息与操作

- 同类资源的名称、作者、时长、状态与操作采用稳定顺序；高频识别信息不只在悬停时出现。
- 图片尺寸加载前有合理占位，避免下载完成后突然推走当前资源；错误占位仍能识别对象。
- 标题可按项目规则限制行数，但完整名称可访问且能在详情核验；不能把唯一标识截成相同文本。
- 同一资源的预览、选择和菜单分别有明确语义，避免一个按钮包裹另一按钮。
- 操作只在项目已支持时出现；不用大量“分享”“下载”“收藏”图标填补卡片空白。
- 缩略图上的文字需在明暗多变的真实图片中保持可读；仅加低透明阴影不保证对比。
- 资源已失效、受限或处理中时说明当前可做什么；不能仅降低透明度让人猜原因。
- 返回集合时尊重已有查询、排序和位置恢复契约；修复网格不擅自新增跨设备历史。

## 选择与播放是不同状态

- 区分键盘焦点、悬停、当前播放、当前预览和已选择；不要让五种状态都只靠同一细边框。
- 多选模式显示选中数量与作用范围；“全选”究竟是当前页还是全部匹配项必须可判断。
- 筛选或翻页后选中项目是否保留，按已有契约明确表达；不能悄悄扩大批量删除范围。
- 取消选择模式回到可理解的位置；不能因清空选择同时停止与选择无关的播放。
- 播放开始、暂停、缓冲、结束与失败由真实状态驱动；点击反馈不能先谎称已播放。
- 当前曲目或视频标题、位置与控制保持对应；“下一项”来自哪一队列应可理解。
- 不默认开启有声自动播放，不把静音等同用户同意连续播放；实际策略服从产品决定和平台能力。
- 已有字幕、转写、音频描述和键盘播放器能力不能在视觉重做时丢失。
- [WAI Media](https://www.w3.org/WAI/media/av/)帮助判断不同音视频内容需要的可访问内容；具体要求按媒体类型与项目目标核实。
- [APG Listbox](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/)不能容纳可独立交互的嵌套按钮；可视网格也不自动要求 `role="grid"`。

## 关键状态

| 状态 | 界面应传达的事实 | 恢复或下一步 |
| --- | --- | --- |
| 第一次无资源 | 集合尚未建立 | 仅给已有权限和能力支持的导入或上级入口 |
| 筛选无结果 | 数据可能存在，但条件没有匹配 | 保留条件并提供可理解的调整方式 |
| 后续批次失败 | 已有资源仍可用 | 在失败位置重试，避免整页清空 |
| 缩略图失败 | 资源本体未必失败 | 显示名称与类型，不伪造预览 |
| 格式不可播放 | 文件存在但当前播放器不支持 | 提供项目已有的替代路径，不偷偷转存外部服务 |
| 播放缓冲 | 当前位置等待数据 | 暂停和退出仍可达，失败时给真实结果 |
| 权限或授权过期 | 当前使用受限制 | 解释允许披露的原因及已有处理路径 |
| 批量操作部分失败 | 哪些完成、哪些仍未完成 | 保留剩余选择，重试范围清楚 |

## 正反例与例外

- 正例：摄影选片页展示完整构图预览，选择框位置稳定，底部显示“已选 6 张”，提交按钮说明用途。
- 反例：点击图片既打开大图又选中；翻页后静默保留选择，删除按钮不说明还包含上一页。
- 正例：播客目录用行展示节目名、发布信息和时长，当前播放状态与行焦点分别表达。
- 反例：为了统一方形封面，把文档和音频都隐藏名称；缺封面时用户无法知道对象是什么。
- 例外：艺术展览的瀑布流可以保留原始比例，但需验证阅读顺序、键盘位置和加载稳定性。
- 例外：专业审片需要并排比较、时间码和密集元信息，不能用“简洁”删掉判断素材所需内容。
- 例外：单个宣传视频不必配播放列表、账号或收藏；播放器功能由实际内容需求决定。
- 例外：受限素材可在选择前展示必要版权条件；降低干扰不能隐藏会改变合法使用范围的限制。

## 项目化示例

假设一个已有图片附件选择器，可以把候选原则写成：

> 范围：文章编辑器的图片选择。沿用现有网格、原生 checkbox 和单次提交；点缩略图只预览，勾选只选择。
> 当前页最多选取的数量来自接口约束；跨页选择沿用已有行为，并显示选择总数与提交范围。
> 透明图采用项目已有棋盘背景；没有预览时保留文件名、类型和尺寸，不引入新的转码依赖。
> 例外：音频附件沿用行列表，不为统一视觉改成图片卡片。

这些条款只在项目确认后生效；它们不赋予批量下载、公开链接或外传附件的授权。

## 可观察的验收

- 用相同名称、长标题、横竖混合、透明图与缺图资源，完成找图、预览、选择、提交的实际任务。
- 只用键盘完成同一路径；焦点与选择可区分，退出预览后能找回资源。
- 在翻页、改变筛选和批量部分失败后核对作用对象；视觉数量与真实提交范围一致。
- 播放已支持的媒体，覆盖缓冲、暂停、失败、结束与返回；界面时间和当前资源对应真实状态。
- 检查窄屏下播放器、字幕、选择栏与列表末尾是否互相遮挡，触控操作不依赖悬停。
- 检查媒体替代内容和控件名称；截图不能证明字幕同步、键盘操作或后端授权有效。

## 来源与采用说明

核实日期：2026-11-11；布局决策为独立综合，不将某个平台播放器或网格审美普遍化。

- [WAI Media](https://www.w3.org/WAI/media/av/)：媒体可访问性的内容规划与播放器入口。
- [WAI Images](https://www.w3.org/WAI/tutorials/images/)：按图片功能选择文字替代，支持缩略图和信息图的不同处理。
- [APG Listbox](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/)：焦点、单多选与可交互子项的模式边界；采用 ARIA 模式还需完整实现其交互。
- [Carbon Empty states](https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states)：支持区分空内容原因及下一步，不要求每个空态配插图。
